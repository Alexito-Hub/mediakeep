# Acerca · MediaKeep

## Una biblioteca que empieza con un enlace

MediaKeep reúne la descarga y el historial de contenido compatible. Puedes iniciar una descarga desde un enlace o compartirlo desde otra aplicación en Android.

## Android y una experiencia web

La aplicación combina Flutter con servicios de procesamiento externos. La disponibilidad de cada plataforma de origen puede cambiar; consulta las notas de la versión antes de instalar.

## El contenido sigue teniendo autor

Utiliza las funciones de descarga para contenido propio o para el que tengas autorización. MediaKeep no transfiere derechos sobre videos, imágenes o audio.
