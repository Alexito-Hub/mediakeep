# Instalación · MediaKeep

## 1. Elige una publicación

Abre Descargas y elige un APK de la versión estable. El APK universal es la opción general; los paquetes por arquitectura solo aparecen cuando se incluyen en esa release.

## 2. Instala en Android

Descarga el archivo y ábrelo desde tu dispositivo. Si Android lo solicita, autoriza la instalación a la aplicación desde la que abriste el APK. Conserva tus archivos y comprueba el editor antes de instalar.

## 3. Actualiza conservando la firma

La nueva versión debe estar firmada con la misma clave que la anterior. Si Android rechaza la actualización, consulta Solución de problemas antes de desinstalar.

## Otras plataformas

La versión web de la aplicación se despliega por separado de este sitio de documentación. Solo utiliza un enlace de aplicación web o un paquete Windows cuando se anuncie en una publicación oficial.

## Identidad y actualizaciones

El identificador Android oficial es com.auralix.mediakeep. Puedes buscar actualizaciones desde Ajustes. En Android se comprueba la integridad del archivo descargado antes de abrir el instalador. Android exige el mismo identificador y la misma firma, además de un número de compilación mayor, para conservar la instalación y sus datos.

## Si usabas una edición anterior

Una edición con otro identificador Android se instala como una aplicación distinta. Conserva tus archivos y exporta lo que permita esa edición antes de migrar; los datos privados no se transfieren automáticamente. No desinstales la aplicación anterior hasta comprobar la nueva.
